# مخطط مصروف الدعاية والإعلانات

تطبيق ويب عربي لتنظيم تعاقدات شركات الدعاية، اليافطات، الأقساط والمدفوعات، مع خريطة سنوية وتقارير قابلة للحفظ بصيغة PDF.

## الوظائف

- عدة شركات وعقود، وعدة يافطات داخل كل عقد.
- دفعة تعاقد منفصلة، وأقساط تلقائية أو يدوية.
- توزيع المدفوعات الجزئية على أقدم الاستحقاقات.
- حالات مستحق، مدفوع جزئيًا، مدفوع ومتأخر.
- تقرير سنوي حسب الشركة والشهر مع طباعة أو حفظ PDF.
- حفظ محلي داخل المتصفح، ونسخ احتياطي واستعادة بصيغة JSON.

> لا تُرسل بيانات المستخدم إلى أي خادم. يُنصح بإنشاء نسخة احتياطية بانتظام.
